# Liderança Psicanalítica (LPS)

## Overview

This project is a Streamlit-based Python application for "Liderança Psicanalítica" (Psychoanalytic Leadership). It offers a custom-styled interface aligned with the LPS brand, facilitating psychoanalytic leadership assessment, team management, and AI-driven insights. The application aims to provide a comprehensive platform for managers to understand team dynamics, individual profiles, and leverage psychoanalytic principles for effective leadership. Key capabilities include user authentication, data isolation for multi-tenancy, a structured leadership assessment (LPSTest), AI-powered consulting (LPSChat), and robust reporting features. The business vision is to empower leaders with psychological insights to foster healthier and more productive work environments, contributing to reduced turnover and improved team cohesion.

## User Preferences

Preferred communication style: Simple, everyday language.

## System Architecture

The application is built primarily on Streamlit for rapid web application development, using Python as the main language. It features a custom-styled interface with LPS brand colors (Navy Blue #0D3B66 and Gold #F4D35E) implemented via embedded CSS.

**Core Features & Design Patterns:**

*   **Authentication & Access Control:** A secure authentication system uses bcrypt for password hashing and Streamlit's `session_state` for session management. It supports two main user types: Managers (full access via login) and Employees (token-based access). Content is gated with a **Vitrine (Showcase) Freemium model**: Home, Dashboard, Sobre, and TeamManagement are open; LPChat, LPTest, Curso, and Mentoria use a "vitrine" approach where page titles, descriptions, and previews are always visible, but functional content (videos, chat input, test forms, scheduling) is blocked behind `render_premium_gate()` for non-premium users. The gate card features gold (#d19f09) styling with WhatsApp CTA. Premium = is_admin OR active payment. Functions: `is_user_premium()`, `render_premium_gate()`. An Employee Access Guard ensures employees remain on their designated assessment page. Official accounts: viviane.lps (Owner, premium), dev.lps (Developer, premium). Personalized welcome message shown on first login ("Bem-vinda, Viviane..." for owner, generic for others).
*   **Data Isolation (Multitenancy):** Implemented to ensure managers can only access and manage their own team's data, guaranteeing data privacy and security through ownership validation and secure data access functions.
*   **Database Management:** Utilizes SQLite (`lps_data.db`) for storing user data, manager/employee details, course progress, and assessment responses. An automated backup system ensures data integrity and allows for recovery.
*   **LPS Course & Assessment:** Features an 8-module course with progress tracking. The LPSTest is a 70-question leadership assessment generating a 7-axis radar chart and Bion role mapping.
*   **Docx-Based Laudo System:** Laudo content is extracted directly from 84 pre-written `.docx` files (42 gestor + 42 funcionario) in `attached_assets/`, NOT generated by AI. File naming pattern: `{DOM_SIGLA}{SEC_SIGLA}_{gestor|funcionario}_timestamp.docx`. Gestor 12 sections: 1. Visão Geral, 2. Essência Psicanalítica, 3. Motivações Inconscientes, 4. Forças, 5. Sombra, 6. Estilo de Liderança e Impacto, 7. Função de Liderança, 8. Dinâmica Emocional (Sinek), 9. Melhor Aproveitamento, 10. Riscos de Alocação, 11. Recomendações de Desenvolvimento, 12. Síntese. Funcionario 12 sections differ: 6. Papéis Grupais (Bion), 10. Recomendações ao Gestor, 11. Reflexões para o Próprio Perfil. Each section displayed as expandable `st.expander`. Key functions: `find_docx_file()`, `extract_docx_profile_text()`, `parse_docx_into_sections()`, `generate_docx_laudo()` (with `generate_ai_laudo()` kept as legacy wrapper). PDFs exported with "Plataforma LPS - Viviane Nishiura" title and #18738c topic headings.
*   **Profile System:** Based on 42 unique profile combinations (archetypes and secondary profiles) stored in `.docx` files, providing detailed insights into strengths, risks, and recommendations.
*   **LPSChat AI Consultant:** An AI-powered consultant accessible to managers after course completion. It leverages OpenAI GPT-4o-mini via the `openai` Python SDK, employee assessment data, and various psychoanalytic methodologies to provide insights into team dynamics, conflict points, and role adequacy. Uses `OPENAI_API_KEY` from Secrets. Chat history limited to last 6 messages with 5-second cooldown between requests.
*   **Team Management & Admin Panel:** Managers can generate unique invite links for employees and monitor their assessment status. An admin panel (`Gestao LPS`) provides advanced functionalities for invite management, user authorization, and comprehensive reporting with CSV exports. The Monitoramento tab displays two distinct result tables: "Resultados do LPTest Lider" (all managers who completed assessments) and "Resultados do LPTest Equipe" (all employees who completed assessments). Each table includes "Visualizar Laudo" and "Baixar PDF" buttons per row for AI-powered laudo generation and PDF export. Super_Admin users (e.g., viviane@lps.com.br) have full access to all laudos across the platform.
*   **Export System:** Supports generating various reports in PDF and CSV formats, including team reports, individual employee profiles, and AI analysis reports, all with LPS branding.
*   **LGPD Compliance:** Includes a dedicated privacy page, consent capture mechanisms, and documentation of user rights.
*   **Legacy/Dormant Stack:** The repository contains configurations for a full-stack TypeScript application (React/Vite frontend, Express.js backend, PostgreSQL/Drizzle ORM) which is currently not active. This indicates a potential future architectural direction or a previous development phase.
